# Catálogo de Águas Lindas – Setor 9

Este projeto é um **mini catálogo online** desenvolvido em HTML, CSS e JavaScript para listar os principais lugares do bairro **Parque da Barragem, Setor 9 – Águas Lindas de Goiás**.  
O catálogo é responsivo e pode ser acessado diretamente pelo celular ou computador.

---

## Funcionalidades
- Exibição de **cards interativos** com:
  - Nome do lugar
  - Descrição
  - Categoria
  - Endereço
  - Foto ilustrativa
  - Link direto para o **Google Maps**
- Campo de **busca por título** (filtra os lugares em tempo real).
- Layout moderno com **efeito hover** nos cards.

---

## Tecnologias utilizadas
- **HTML5** → Estrutura da página  
- **CSS3** → Estilização e responsividade  
- **JavaScript (ES6)** → Renderização dinâmica dos cards e filtro de busca
